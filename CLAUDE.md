# Design Philosophy

Treat the existing portfolio as a reference for:

- Overall content organization
- Personal branding
- Tone
- Information architecture

Do **not** feel constrained by the current implementation.

Your objective is to create a significantly more polished, modern, and visually impressive portfolio while preserving the overall purpose of the website.

You are encouraged to improve:

- Layout
- Visual hierarchy
- Typography
- Color usage
- Section flow
- Card designs
- Animations
- Spacing
- Micro-interactions
- Responsiveness
- Overall user experience

The final website should feel like the next evolution of the current portfolio rather than a simple refresh.

Aim for a portfolio that looks comparable to high-quality modern developer portfolios while remaining professional enough for recruiters and enterprise clients.

# Workflow

1. Analyze the existing portfolio website.
2. Understand what works well and what feels outdated.
3. Review the resume located at:

   ```
   @src/public/resume/resume.pdf
   ```

4. Compare both sources and identify:
   - Missing information
   - Outdated content
   - Weak sections
   - Opportunities for improving both design and user experience
5. Redesign or refactor sections where doing so creates a noticeably better portfolio.
6. Preserve only the aspects of the current website that contribute positively to the overall experience.
7. Deliver a cohesive, modern portfolio that accurately represents the resume.

# General Requirements

- Use the resume as the single source of truth for all personal information.
- The current portfolio is a reference—not a constraint.
- Improve both the content and the visual presentation wherever appropriate.
- Feel free to redesign sections if a better solution exists.
- Maintain consistency across the entire website.
- Keep the experience clean, modern, responsive, and accessible.
- Do not invent work experience, skills, certifications, or achievements.
- Use placeholder content only where explicitly requested.

# Quality Expectations

The finished portfolio should:

- Have a premium, modern appearance.
- Create a strong first impression within a few seconds.
- Clearly communicate seniority and technical expertise.
- Showcase projects and experience effectively.
- Follow modern UI/UX best practices.
- Feel intentional and cohesive across all sections.
- Be fully responsive across desktop, tablet, and mobile devices.
- Be suitable for sharing with recruiters, engineering managers, clients, and potential employers.

Do not settle for the simplest implementation. Prefer thoughtful layouts, strong visual hierarchy, tasteful animations, and refined spacing whenever they improve the overall experience.

# Think Like a Designer

Before implementing changes, critically evaluate every section of the portfolio from the perspective of a recruiter or potential client.

For each section, ask yourself:

- Does this communicate value effectively?
- Is this visually engaging?
- Can the information be presented more clearly?
- Would a senior engineer be proud to showcase this?

Iterate on your design decisions until the portfolio feels polished, modern, and production-ready rather than merely functional.
